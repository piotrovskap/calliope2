### **Onboarding a Client Using Tekion as Their CRM Provider**

## **Introduction**

The **onboarding process** for a client using **Tekion as their CRM provider** involves multiple teams working together to ensure a smooth integration. From setting up access to validating data synchronization and troubleshooting potential issues, this document provides a structured framework to guide each phase of the process.

The onboarding workflow is divided into **nine key sections**, covering everything from **prerequisites and technical integration** to **go-live procedures and post-onboarding support**.

Each section is designed to provide clear **technical guidance** for developers, product managers, client activation teams, and support teams.

### The following steps outline the **end-to-end process**:

1.  **Prerequisites & Requirements** –the client will create a profile or provide us access to a profile to be able to collect the data. We need the following permissions:

    1.  Deferred Service Report View

    2.  Service Advisor Coupon View

    3.  Service Summary Report View

    4.  Service Visibility Report View

    5.  WIP Service Report View

    6.  Sales Report Create

    7.  Sales Report Edit

    8.  Sales Report View

2.  **Key Stakeholders & Responsibilities** – *Identifies the teams involved and their roles in the onboarding process.*

    1.  **Client Success**: obtains the CRM login from the client with an account created for us

    2.  **CAST**: completes the following steps

        1.  **Provide** a cat.dasclient email

        2.  **Share** the clerk number with the dealer to set up a login.

        3.  **Ensure** the login is provided and tested by CAST. Once confirmed as working, proceed to the next step..

        4.  **Add** the credentials to LastPass.

        5.  **Submit** the request through the **Team CDXP Channel**, including instructions to reference LastPass using the client name and client ID. ID

        6.  **Assign** the request to **Priyanshu** for further action.

    3.  **Development**: *Completes the process by setting things up to collect the data*

3.  **High-Level Onboarding Workflow** – *Provides a structured overview of the onboarding phases and expected timelines.*

4.  **Technical Integration Steps** – *Covers API setup, data synchronization, and handling of data transformations.*

5.  **Testing & Validation** – *Ensures accurate data transfer and verifies system integrity before going live.*

6.  **Go-Live Process** – *Outlines the final checks and monitoring steps before the system is fully operational.*

7.  **Post-Onboarding Support & Troubleshooting** – *Details how to handle errors, log issues, and escalate problems.*

8.  **FAQs & Additional Resources** – *Answers common questions and provides links to documentation and escalation paths.*
