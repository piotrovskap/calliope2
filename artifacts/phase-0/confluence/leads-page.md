This page is similar to Inbox page: here all leads are displayed, but they are grouped in the table. Provider can apply filters (the same which are used on Inbox page). By default the filter “Contact details contain one Email / Phone” is applied.  

Clicking visitor’s name, conv with him is opened on Inbox page.

User can switch between "Open" and "Closed" groups of leads; close and reopen leads. Unlike Inbox page, leads can also be deleted. Deleting means that a lead is removed from all places in the database, so this is an irreversible action.

Provider can add a new lead. After its creation, redirect to Inbox page will occur.

Leads can be exported to .xml.

Leads can be sorted desc / asc by the date of the last visitor’s message.
