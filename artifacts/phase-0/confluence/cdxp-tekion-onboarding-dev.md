Onboarding Documentation</span>**

**<span colorid="u0horog4ni">Step 1:</span>**\
<span class="legacy-color-text-default">This step outlines the process of configuring the data pull settings for a client within the Analytics_Clients table. These settings determine whether the system is enabled to retrieve CRM data, DMS data, and whether the client is designated as active within the system.</span>

**<span colorid="r9wa8g1mdz">Server Details</span>**

- **<span colorid="op4ritsd9z">Server:</span>**<span class="legacy-color-text-default"> 32-server / 3BHSETL01 (10.254.210.32)</span>

- **<span colorid="a08qmvsrth">Database:</span>**<span class="legacy-color-text-default"> EDW_target</span>

- **<span colorid="jgpjyw6204">Table:</span>**<span class="legacy-color-text-default"> Analytics_Clients</span>

**<span colorid="i9z19poct0">Parameters to Update</span>**

**<span colorid="uevwou7ded">IsCRM</span>**

- <span class="legacy-color-text-default">Set IsCRM = 1 to activate CRM data retrieval for the client.</span>

**<span colorid="k0k072h0xf">IsDMS</span>**

- <span class="legacy-color-text-default">Set IsDMS = 1 to activate DMS data retrieval for the client.</span>

**<span colorid="pp1t2vu48h">IsInternal</span>**

- <span class="legacy-color-text-default">Set IsInternal = 1 to designate the client as active within the system.</span>

**<span colorid="uq7f2rcavd">CRMProvider</span>**

- <span class="legacy-color-text-default">Set CRMProvider = 'Tekion' to designate Tekion as the CRM provider for the client.</span>

**<span colorid="l3txfkezci">Update Query</span>**

<span class="legacy-color-text-default">Execute the following SQL query to configure the required parameters for the designated client:</span>

<span colorid="vmagz1mg2z">UPDATE Analytics_Clients</span>

<span colorid="wvc09woonz">SET </span>

<span colorid="d1hg7uuzrv"> IsCRM = 1, -- Enable CRM data pull</span>

<span colorid="gtggi5pqvr"> IsDMS = 1, -- Enable DMS data pull</span>

<span colorid="lbskyk4chh"> IsInternal = 1, -- Mark the client as active</span>

<span colorid="vmhwmyjyrx"> CRMProvider = 'Tekion' -- Specify CRM provider</span>

<span colorid="r0f4qjs127">WHERE ClientID = (Client_ID);</span>

*<span colorid="g8h953lc0s">Replace (Client_ID) with the actual Client ID assigned to the client.</span>*

**<span colorid="ys2v7zq3ba">Step 2:</span>**\
<span class="legacy-color-text-default"> 1. Navigate to the Tekion CRM portal: </span><a href="https://app.tekioncloud.com/login?redirectTo=/crm/leads" class="external-link" rel="nofollow">https://app.tekioncloud.com/login?redirectTo=/crm/leads</a>

<span class="legacy-color-text-default">2. Enter the client's Username and Password from LastPass, along with the authentication code obtained from Clerk.</span>

<span class="legacy-color-text-default">3. Upon successful login, you will be redirected to the following page. If the client is a group client, you can select the client name by clicking on the top-right corner.</span>

<span colorid="pbm2zxkg3s"> </span><span class="legacy-color-text-default">6. Select Created Date as the filter criterion. During Tekion onboarding, data for the last 3 years is retrieved. **<span colorid="st5hjmvg6k">Note:</span>**

- <span class="legacy-color-text-default">The Tekion Portal enforces an export limit of 10,000 rows per session. If the dataset exceeds this limit, it must be divided into smaller date ranges and downloaded in multiple batches to retrieve the complete 3-year data history.</span>

- For Example, As there are 40,159 results, we should split the dataset into smaller chunks and download multiple CSV files.
