**<span colorid="uoc93cgxiu">Step 1:</span>**\
<span class="legacy-color-text-default">This step outlines the process of configuring the data pull settings for a client within the Analytics_Clients table. These settings determine whether the system is enabled to retrieve CRM data, DMS data, and whether the client is designated as active within the system.</span>

**<span colorid="oltw2t3f4h">Server Details</span>**

- **<span colorid="ovp4of7s1m">Server:</span>**<span class="legacy-color-text-default"> 32-server / 3BHSETL01 (10.254.210.32)</span>

- **<span colorid="i482ugfljv">Database:</span>**<span class="legacy-color-text-default"> EDW_target</span>

- **<span colorid="t17g8axrn0">Table:</span>**<span class="legacy-color-text-default"> Analytics_Clients</span>

**<span colorid="b34hqbjzxz">Parameters to Update</span>**

**<span colorid="e4q1lp02w3">IsCRM</span>**

- <span class="legacy-color-text-default">Set IsCRM = 1 to activate CRM data retrieval for the client.</span>

**<span colorid="ewlte2s1lh">IsDMS</span>**

- <span class="legacy-color-text-default">Set IsDMS = 1 to activate DMS data retrieval for the client.</span>

**<span colorid="vd0ukn3ntp">IsInternal</span>**

- <span class="legacy-color-text-default">Set IsInternal = 1 to designate the client as active within the system.</span>

**<span colorid="d780b273g6">CRMProvider</span>**

- <span class="legacy-color-text-default">Set CRMProvider = 'vinSolutions' to designate VinSolutions as the CRM provider for the client.</span>

**<span colorid="f3ndhi845g">Update Query</span>**

<span class="legacy-color-text-default">Execute the following SQL query to configure the required parameters for the designated client:</span>

<span colorid="mst49aqu4p">UPDATE Analytics_Clients</span>

<span colorid="ec20r6r58r">SET </span>

<span colorid="ogq8urjkr8"> IsCRM = 1, -- Enable CRM data pull</span>

<span colorid="sjixd5lzuj"> IsDMS = 1, -- Enable DMS data pull</span>

<span colorid="gbkorj60lp"> IsInternal = 1, -- Mark the client as active</span>

<span colorid="s3d0poth4l"> CRMProvider = 'vinSolutions' -- Specify CRM provider</span>

<span colorid="ys6kpzvue0">WHERE ClientID = (Client_ID);</span>

*<span colorid="vvkbxib529">Replace (Client_ID) with the actual Client ID assigned to the client.</span>***<span colorid="u6iav5jq47"> </span>**
