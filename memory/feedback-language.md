Use English for anything publicly facing or permanently recorded: docs, sheets, wiki pages, artifacts, code comments, commit messages, GitHub issues, meeting notes.

Use Costa Rican Spanish for messages posted to #das-digital in Slack, unless the user specifies otherwise.

Use English for everything else: DMs, internal memory files, repo skill files, direct messages to individuals.

**Why:** #das-digital is a Spanish-speaking team channel. All artifacts and docs may be shared with DAS stakeholders (Dan, Alex, Mike) or referenced externally, so they stay in English.

**How to apply:** Before writing any Slack message to #das-digital, default to Spanish. Before writing any doc, sheet, wiki page, or artifact, default to English.
